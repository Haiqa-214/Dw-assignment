1. How to run

Open index.html in browser or use Live Server(In VS code).

2. Stack & design choices

Used HTML, CSS, JS as I have knowledge of only these.
I used card layout to separate input and output clearly.
Tip buttons are used for quick selection.

3. Responsive & accessibility

App works on mobile (360px) and laptop (1440px) using flexible width.
I added labels and error messages for accessibility.
Tab navigation works through inputs.

4. AI usage
   Chatgpt
   Modified the code by simplifying functions and fixing selectors to match my HTML.

5. Honest gap

The UI is basic and not highly animated.
If I had more time, I would improve design, add transitions, and better button active states.

6. Rounding policy
   Standard rounding to 2 decimal places using toFixed(2) for all outputs.
